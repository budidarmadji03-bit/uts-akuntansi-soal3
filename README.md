# UTS Coding Akuntansi — Soal 3

Repository ini merapikan jawaban Soal 3.1a, 3.1b, dan 3.2 UTS Pemrograman/Coding Akuntansi FEB UNDIP dalam folder `soal3/`.

## Isi repository

```text
.
├── index.html                 # meneruskan ke website/formulir
├── README.md
└── soal3/
    ├── 3.1a_prompt_gemini.md
    ├── 3.1b_verifikasi_psak2.md
    ├── 3.2_audit_trail.sql
    ├── voucher_kas_keluar.html
    ├── app.js
    ├── style.css
    ├── supabase-config.js
    ├── docs/
    └── supabase/
```

Folder `soal3/` berisi jawaban, source aplikasi, SQL, dokumentasi, dan skrip pendukung. Lihat [README Soal 3](./soal3/README.md) untuk setup, status integrasi, dan pengujian.

## Menjalankan aplikasi

Buka [website GitHub Pages](https://budidarmadji03-bit.github.io/uts-akuntansi-soal3/) atau jalankan `soal3/voucher_kas_keluar.html` dengan Live Server di VS Code. Aplikasi membutuhkan koneksi internet untuk CDN. Supabase belum aktif sampai project dan konfigurasi client-side disiapkan; tanpa konfigurasi, aplikasi tidak menyimpan transaksi.
